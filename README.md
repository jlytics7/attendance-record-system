# 🗓️ Attendance Record System

A simple desktop attendance tracker built with **Java Swing**. Log in, mark people as **Present** or **Absent** with automatic timestamps, view the live record list, and save everything to a text file.

## ✨ Features

- Login screen built with Java Swing
- Mark attendance as **Present** or **Absent** — every entry is timestamped
- Live attendance list during the session
- Save records to `attendance_records.txt`

## 🛠 Tech Stack

- Java (Swing / AWT), no external dependencies

## 🚀 Getting Started

### Prerequisites

- JDK 8 or later

### Run

```bash
javac LoginAttendance.java
java LoginAttendance
```
